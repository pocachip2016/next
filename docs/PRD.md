# PRD: next (rightwatch)

## 목표
웹하드에서 불법 유통되는 VOD 콘텐츠를 자동 모니터링하고, 저작권자(CP)별로 탐지 결과을 취합·리포팅하여 신속한 삭제 요청과 저작권 보호를 실현한다.

## 사용자
- **CP(저작권자)**: 자신의 콘텐츠가 어디서 불법 유통 중인지 실시간 모니터링, 삭제 현황 추적
- **운영자**: 모니터링 요청 관리, 크롤러 스케줄 설정, CP별 리포트 생성 및 발송

## 핵심 기능
1. **게시판 캐싱 크롤** — ondisk 등 웹하드 게시판 주기적 전수 스크래핑, 신규/갱신 게시물을 `post` 테이블에 적재
2. **콘텐츠↔게시물 매칭** — CP별 관심 콘텐츠(title, 배우, 감독 등)를 게시물 제목/설명과 매칭하여 `check_list`에 기록
3. **변형 패턴 탐지** — 한글 "기도"→"7ㅣ도" 같은 모니터링 회피 변형을 자모분해, homoglyph 정규화, synonym 사전으로 탐지
4. **상태 관리** — 탐지 후 운영자 승인, CP에 통보(이메일), 삭제 요청 추적, 재확인 → 종결
5. **CP별 리포트** — 기간별 탐지 건수, 삭제율, 주요 웹하드 통계를 CP 대시보드에 표시

## MVP 포함 범위 (M1~M4)
- ondisk 모니터링만 우선 완성
- 게시판 캐싱 + 제목정규화 기반 매칭 + 규칙기반 변형탐지
- 스케줄러 기반 주기적 갱신
- 기본 CP 집계 API

## MVP 제외 사항
- filesun, torrent 등 다수 웹하드 (M4 이후 확장)
- 영상 DNA 검증 (M7, 선택사항)
- 머신러닝 기반 매칭/이상탐지 (후속 고도화)
- 이미지 유사도 검색

## 성공 지표
- **탐지 정확도**: 불법 VOD 탐지율(recall) ≥ 80% (샘플 테스트 기준)
- **오탐률**: ≤ 5% (false positive)
- **처리 속도**: 탐지→통보→재확인까지 평균 48시간 이내
- **크롤 안정성**: 월 99% 정상 수행 (계획된 유지보수 제외)
